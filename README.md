# Neon Counter

A sleek, interactive counter application featuring a dark interface with neon-green accents and intuitive controls.

## Overview

Neon Counter is a beginner-friendly web development project created to practise the fundamentals of HTML, CSS, and JavaScript. It combines a minimal visual design with simple, interactive counter functionality.

## Live Demo
Check out the live project here: https://srushtinavale-02.github.io/Neon-Counter/

## Features

- **Increment:** Increase the counter value.
- **Decrement:** Decrease the counter value.
- **Reset:** Return the counter to zero.
- **Dark UI:** A clean, dark interface with neon-green highlights.
- **Interactive Controls:** Distinct buttons for each counter action.

## Tech Stack

- HTML5
- CSS3
- JavaScript
